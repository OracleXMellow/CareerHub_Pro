# CareerHub Pro - Project Instructions

## Overview
Career management web application with resume building, job tracking, AI tools, cover letter generation, and document storage.

## Tech Stack
- Next.js 14 App Router, React 18, TypeScript
- Prisma ORM with PostgreSQL
- NextAuth.js v4 (credentials provider, email/password)
- AWS S3 for document storage
- Abacus AI LLM API for AI features
- Tailwind CSS 3, Framer Motion, Recharts

## Color Scheme
- Primary: Teal `hsl(170 70% 35%)` (light), `hsl(170 70% 40%)` (dark)
- Professional blue-teal aesthetic throughout
- Status colors: Blue (wishlist), Yellow (applied), Purple (interview), Green (offer), Red (rejected)

## Architecture
- Route groups: `(authenticated)` with AppShell layout (sidebar navigation)
- Pages: Dashboard, Resumes, Jobs, AI Tools, Cover Letters, Documents
- Auth: Login/Signup at root level, middleware protects authenticated routes
- API routes: `/api/resumes`, `/api/jobs`, `/api/cover-letters`, `/api/documents`, `/api/dashboard`
- AI streaming routes: `/api/ai/suggestions`, `/api/ai/analyze-job`, `/api/ai/cover-letter`
- Upload routes: `/api/upload/presigned`, `/api/upload/complete`

## Key Design Decisions
- Resume data stored as JSON strings in DB (experience, education, skills arrays)
- Two resume templates: "modern" (teal accent) and "classic" (traditional serif)
- Job statuses: wishlist, applied, interview, offer, rejected
- Documents stored in S3 with presigned URLs (private by default)
- AI features use gpt-5.4-mini model with SSE streaming
- Cover letter generation uses plain text streaming (not JSON)
- Resume suggestions and job analysis use JSON buffered streaming

## User Preferences
- Professional teal/blue color scheme
- Clean, minimal design with subtle animations
- Sidebar navigation with user info and sign-out

## AI Reliability Layer (lib/ai.ts)
All 8 AI API routes now share a resilient LLM helper at `nextjs_space/lib/ai.ts`. Exports:
- `AIError` (status + userMessage), `extractJson<T>()` (tolerant JSON extraction: strips code fences, balanced-bracket walker), `callLLM()` (AbortController timeout, retries w/ exp backoff on network/timeout/429/5xx), `callLLMJson<T>()` (JSON parse + one corrective retry on malformed output), `fetchLLMStream()` (retries the INITIAL streaming connection only, clears connect timer once headers arrive so body streams freely), `aiErrorResponse()` (standard JSON error Response).
- Non-streaming routes (job-match, interview-prep, ats-check, parse-cv [90s timeout for PDFs], parse-linkedin) use callLLMJson + output normalization so UI never crashes on missing fields.
- Streaming routes (suggestions, analyze-job, cover-letter) use fetchLLMStream and keep their SSE logic.
- Client components now surface the server's specific `data.error` message instead of generic toasts.

## ATS Checker — BambooHR / Greenhouse / Workable approach
The ATS checker (`/api/ai/ats-check`) now supports two modes:
- **Generic mode** (no job description): BambooHR-style parseability + general best practices. 5 dimensions: Parseability & Structure (25), Quantified Impact (25), Keyword Optimisation (20), Experience & Title Alignment (15), Completeness & Polish (15).
- **Job-spec mode** (job description provided): Greenhouse scorecard + Workable keyword matching. 5 dimensions: Parseability & Structure (20), Keyword & Skills Coverage (30), Quantified Impact & Evidence (20), Experience & Title Alignment (15), Tailored Fit & Completeness (15). Returns matchedKeywords, missingKeywords, topRecommendations, and tailoredSuggestions with before/after rewrites.
The UI shows an optional job description textarea, collapsible scorecard categories, keyword badge grids, and expandable tailored rewrite suggestions. Job Matcher remains as a quick-match tool with a tip linking to the deep-dive ATS analysis.

## Tailor CV to Job Feature (Aug 2026)
- **API:** `/api/ai/tailor-cv` (POST) — takes `{ resumeData, jobDescription }`, uses `callLLMJson` (90s timeout) to return a fully tailored ResumeData + `changesSummary[]` array. Honesty guardrail: AI rephrases/reorders real content, never fabricates.
- **Component:** `tailor-cv.tsx` — two-step dialog (input → review). Step 1: shows source resume info + job desc textarea. Step 2: shows changes summary (collapsible badges), Preview/Details toggle (reuses `ResumePreview`), and "Save as New Resume" + "Export PDF" buttons.
- **Wiring:** "Tailor" button (Sparkles icon) on each resume card in `resumes-content.tsx`, opens TailorCV dialog.
- Saves tailored version as a NEW resume (title auto-generated: "Original Title — Target Role"). Never overwrites original.
- Export reuses existing `/api/resumes/export-pdf` endpoint.
